# user-auth-fastapi


## Getting Started
This project use uv for fast python package management . 

## Tech Stack 
SQLModel for pydantic and Orm 
pwdlib with  Argon2 for secure , battled-tested modern algorithm .


## Prerequisite
Make sure `uv` is installed :
```bash
# If you don't have it yet:
curl -LsSf https://astral.sh/uv/install.sh | sh

```
To add $HOME/.local/bin to your PATH, either restart your shell or run:
```
    source $HOME/.local/bin/env (sh, bash, zsh)
    source $HOME/.local/bin/env.fish (fish)
```

## Installation and Setup
1. Clone the repo 
``` 
git clone https://github.com/Nrams1/user-auth-fastapi.git 
```
2. Move inside the folder 
```
cd user-auth-fastapi/
```
